كيف تتم الخدمة؟

  1. تواصل معنا

    اتصال، واتساب، أو طلب إلكتروني.

  2. أرسل البيانات

    نستلم البيانات المطلوبة لإعداد العقد.

  3. نُعد العقد ونراجعه

    إعداد بيانات العقد ومراجعتها قبل الإرسال.

  4. التوثيق عبر إيجار

    يتم إرسال العقد للأطراف لإكمال إجراءات الموافقة والتوثيق عبر شبكة إيجار.

تحتاج عقد إيجار لغرض محدد؟

الضمان المطور

عقد إيجار إلكتروني موثق لإثبات السكن بحسب متطلبات الجهة.

حساب المواطن

عقد إيجار إلكتروني موثق للاستخدام بحسب متطلبات البرنامج.

حافز

عقد إيجار إلكتروني يمكن استخدامه بحسب الاشتراطات المطلوبة من الجهة.

بلدي

عقد إيجار موثق للاستخدام في الإجراءات التي تتطلب عقد إيجار.

اعتماد العقد أو قبوله لدى أي برنامج أو جهة يخضع لشروط ومتطلبات تلك الجهة، ولا يضمن مكتب الهيف أهلية المستفيد للبرنامج.

الأسئلة الشائعة

هل الخدمة متاحة خارج الرياض؟

نعم، الخدمة إلكترونية ومتاحة للعملاء في جميع مناطق المملكة.

هل العقد يتم عبر شبكة إيجار؟

نعم، يتم إعداد وتسجيل العقد وإرساله للأطراف لاستكمال إجراءات التوثيق عبر شبكة إيجار.

ما البيانات المطلوبة لإنشاء العقد؟

نبدأ بالبيانات الأساسية، ثم يتم استكمال بيانات العقد والمستندات المطلوبة أثناء إجراءات الخدمة.

متى يتم إرسال العقد للأطراف؟

بعد اكتمال البيانات ومراجعة العقد يتم إرساله للأطراف لاستكمال إجراءات الموافقة والتوثيق عبر شبكة إيجار.

هل أستطيع الاتصال قبل بدء الطلب؟

نعم، يمكنك التواصل مباشرة مع مكتب الهيف قبل بدء إجراءات العقد عبر الاتصال أو واتساب.

ماذا عن السنوات الإضافية؟

تطبق رسوم شبكة إيجار الرسمية المتعلقة بالمدة الإضافية.

هل العقد مناسب للضمان أو حساب المواطن؟

يمكن استخدام عقد الإيجار الموثق بحسب متطلبات الجهة المعنية، واعتماد العقد يخضع لشروط تلك الجهة.
